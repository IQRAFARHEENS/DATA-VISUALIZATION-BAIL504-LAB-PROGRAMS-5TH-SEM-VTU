# Data Visualization Lab — BAIL504

Lab programs for the **Data Visualization Lab (BAIL504)**, VTU 5th Semester, Dept. of CSE (AI & ML).

Each program is built in **Tableau** or **Power BI** and lives in its own folder with a dedicated README, the dataset used, the workbook/report file, and step-by-step screenshots.
