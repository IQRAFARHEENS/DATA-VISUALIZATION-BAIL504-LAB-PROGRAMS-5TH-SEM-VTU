## 🔹 1. Components of Power BI

Power BI includes the following major components:

### Power BI Desktop

Power BI Desktop is used to create reports and data visualizations from datasets.

### Power BI Gateway

Power BI Gateway allows users to connect Power BI with on-premises data sources and keep data refreshed without moving the data.

### Power BI Mobile Apps

Power BI Mobile Apps allow users to stay connected to their data from anywhere.

Power BI apps are available for:

- Windows
- iOS
- Android

### Power BI Service

Power BI Service is a cloud-based service used to publish Power BI reports and data visualizations.

---

## 🔄 2. Flow of Work in Power BI

A typical Power BI workflow involves different types of content and activities.

The general flow is:

```text
Data Sources
     ↓
Semantic Models
     ↓
Power BI Desktop
     ↓
Reports & Visualizations
     ↓
Dashboards
     ↓
Power BI Service / Apps
     ↓
Business Users
````

A Power BI designer collects data from semantic models, brings it into Power BI Desktop for analysis, and creates reports containing visualizations.

Visualizations can then be pinned to dashboards and shared with business users.

---

## 📊 3. Power BI Content

### Visualization

A visualization is a type of chart or visual created using Power BI.

Visualizations display data from reports and semantic models and allow users to interact with the data.

### Semantic Model

A semantic model is a container of data used to build reports, dashboards, and apps.

It can contain data from sources such as:

* Excel files
* Databases
* Salesforce
* Other data sources

### Dashboard

A dashboard is a single screen containing interactive visuals, text, and graphics.

It presents important metrics or information in one place.

### Report

A report consists of one or more pages containing interactive visuals, text, and graphics.

A report is based on a semantic model.

### App

An app allows designers to bundle and share related dashboards, reports, and semantic models.

## 🖥️ 4. Power BI Desktop Interface

Power BI Desktop provides the main environment for creating reports and visualizations.

The major areas of the interface include:

* **Ribbon** – Contains controls and options for building reports.
* **Views** – Includes Report View, Data View, and Model View.
* **Canvas** – Main design area where visualizations are created and arranged.
* **Page Selector** – Used to navigate between report pages.
* **Filters** – Used to filter data.
* **Visualizations** – Contains available visualization types.
* **Fields** – Displays tables and fields available in the data model.

## 💻 5. Downloading and Installing Power BI Desktop

Power BI Desktop is available in both 32-bit and 64-bit versions.

### Installation Steps

1. Download Power BI Desktop from the official Microsoft website.
2. Select **Power BI Desktop**.
3. Open the advanced download option.
4. Select the language as **English**.
5. Download the required installer.
6. Open the downloaded `.exe` file.
7. Follow the installation wizard.
8. Click **Finish** after installation.
9. Launch Power BI Desktop.

The application opens with a blank report.

## 🧩 6. Major Components of Power BI Desktop

### Power Query Editor

Power Query Editor is used for cleansing and transforming data and allows users to work with datasets from multiple sources.

### Power View

Power View is a data visualization tool used to create charts and maps for presenting data.

### Power Map

Power Map is a 3D map visualization tool used to visualize geographical data.

### Power Pivot

Power Pivot is used for data modelling and creating relationships between datasets. It also supports complex calculations using DAX functions.

### Power Q&A

Power Q&A allows users to ask questions about data using natural language and obtain answers from the dataset.

---

## 📈 7. Building Reports in Power BI

Power BI Desktop provides a **Report View** for creating visualizations and reports.

The main areas include:

1. **Ribbon** – Displays common tasks related to reports and visualizations.
2. **Canvas** – Main area for creating and arranging visualizations.
3. **Pages Tab** – Used to select or add report pages.
4. **Filters Pane** – Used to filter data visualizations.
5. **Visualizations Pane** – Used to add, modify, and customize visualizations.
6. **Format Pane** – Used to design and format reports and visualizations.
7. **Fields Pane** – Displays the available fields from the data model.
